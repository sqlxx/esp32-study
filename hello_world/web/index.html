ESP32 Web Bluetooth

Android Chrome：连接 ESP32-Hello， 读写 Service 0xFFE0 / Characteristic 0xFFE1。 Write 命令：角度 0~180、scan、stop、spd:1~10。

怎么打开
1. 电脑 Chrome：在本目录执行 python3 -m http.server 8080， 打开 http://localhost:8080
2. Android Chrome：需要 HTTPS。可执行 python3 serve.py， 手机访问提示的地址（证书警告选继续即可）
3. 不支持 iPhone Safari
